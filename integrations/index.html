The studio is deliberately open: everything exports to CSV or JSON so it drops straight into the tools you already use.

AutoCAD / BIM

Cost planning

Area × rate totals export ready for a cost plan or feasibility model.

Local backup

Every saved project downloads as JSON — keep your own versioned copies.

No lock-in

There is no proprietary database here. Open formats mean your data stays yours and moves freely between tools.
